# 字数统计 · EdgeEver 插件

## 1.1.0

- 正文／Markdown 源码两种口径，可选择优先选区、整篇笔记、仅选区。
- 正文去除格式标记、图片和链接目标地址；显示出来的链接文字仍计入正文。默认排除代码，可勾选包含代码。
- 汉字覆盖扩展汉字；英文／拉丁字母词支持重音和词内连字符；数字组独立计数。
- 字符使用 Unicode 字素簇计数，家庭 emoji、肤色 emoji 和组合重音各按一个可见字符计算。
- 读取失败可重试，关闭面板后迟到响应不再更新界面，独立样式前缀避免与网页收藏冲突。

## 安装和使用

在 EdgeEver 扩展管理中使用仓库 https://github.com/ZhenYu-Jiang/edgeever-word-count 安装或更新。打开文本笔记，执行「字数统计」命令。选区或笔记变化后点击刷新。

“正文文本行数”指提取后的文本行，和编辑器屏幕折行不同。预计阅读时间以汉字 400 字／分钟、拉丁字母词 200 词／分钟估算，属于参考值。当前编辑器的未保存内容也可统计；本插件只读取，不修改笔记。

正文解析使用标准 Markdown/GFM；宿主专有嵌入、数学公式等不承诺和实际渲染字数完全一致。选区有 Markdown 时按相同规则解析；旧宿主仅返回纯文本时会显示说明。

## 开发

编辑 `src/main.js`，执行 `npm ci`、`npm run build`、`npm test`。首次测试需 `npx playwright install chromium`；使用本机 Chrome 可设置 `PLAYWRIGHT_CHANNEL=chrome`。

`main.js` 是提交到仓库的单文件分发产物，包含 Marked 及其 MIT 许可，不需运行时下载依赖。CI 验证构建结果及隔离浏览器测试；并在版本标签存在时发布安装资产。测试不使用真实笔记数据。
